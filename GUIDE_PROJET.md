# Documentation du Projet : Prot-App

Ce document explique la structure et le contenu du projet **Prot-App**, un portfolio professionnel développé avec React.

## 📁 Structure des Dossiers

- **`public/`** : Contient les fichiers statiques (index.html, icônes, etc.).
- **`src/`** : Le cœur de l'application contenant le code source.
  - **`assets/`** : Images, logos et autres ressources médias.
  - **`components/`** : Les blocs réutilisables de l'interface utilisateur.
- **`build/`** : (Généré) Contient la version optimisée pour le déploiement.

## 🧩 Composants Principaux (`src/components/`)

L'application est structurée en une seule page (Single Page Application) composée des sections suivantes :

1.  **`Header.js`** : La barre de navigation permettant de se déplacer entre les sections.
2.  **`Hero.js`** : La section d'accueil avec une introduction percutante et un appel à l'action.
3.  **`About.js`** : Une présentation détaillée du profil professionnel.
4.  **`Skills.js`** : Une grille ou liste affichant les compétences techniques et outils maîtrisés.
5.  **`Projects.js`** : La vitrine des réalisations avec descriptions et liens.
6.  **`ContactMe.js`** : Un formulaire ou des informations pour entrer en contact.
7.  **`Footer.js`** : Le pied de page avec les liens sociaux et droits d'auteur.

## 🚀 Scripts Disponibles

Dans le répertoire du projet, vous pouvez exécuter :

- **`npm start`** : Lance l'application en mode développement (http://localhost:3000).
- **`npm run build`** : Compile l'application pour la production dans le dossier `build`.

## 🛠️ Technologies Utilisées

- **React.js** : Framework principal.
- **CSS Vanilla** : Utilisé pour le design élégant et personnalisé.
- **React Icons** : Bibliothèque d'icônes pour l'aspect visuel.
